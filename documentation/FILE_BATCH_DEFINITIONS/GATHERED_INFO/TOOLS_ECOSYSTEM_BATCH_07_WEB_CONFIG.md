# Tools Ecosystem - Native Web Search Configuration

## Simple Sentence Form

**Overview:** The Native Web Search tool configuration defines comprehensive web search capabilities, Anthropic native integration, operation definitions, and model compatibility through JSON-driven metadata for dynamic tool discovery and native search orchestration.

## Code & Explanation

**Architecture Overview:**

### JSON-Driven Native Search Discovery
- **Anthropic Native Tool Declaration**: Complete tool definition enabling automatic discovery of native web search capabilities with Anthropic integration
- **Advanced Capability Declaration**: Comprehensive capability list including web_search, filtered_search, content_search, query_validation, search_suggestions, real_time_results, and source_verification
- **Native Search Operation Definition**: Detailed operation specifications with required/optional parameters for each native search function
- **Model-Specific Integration**: Explicit model compatibility declaration for Claude Sonnet 4, Claude 3.5 Sonnet, and Claude 3.7 Sonnet

### Native Search Ecosystem Integration
- **4-File Native Architecture Declaration**: Explicit file path definitions for native search logic, button, UI, and configuration components
- **Claude Model Compatibility**: Specific model support declaration for optimal native web search execution across Claude variants
- **Native Search Cost Transparency**: Clear cost estimation (0.01 base) for native search workflow planning and budget optimization
- **Native Search Tag Classification**: Comprehensive tagging for search, web, research, realtime, native, anthropic, information, sources, validation, and suggestions

### Native Search Operation Metadata
- **Native Function Signature Definition**: Complete parameter specifications for perform_web_search, perform_filtered_search, perform_content_search, validate_search_query, and get_search_suggestions operations
- **Real-Time Capability Declaration**: Explicit real-time results capability for live information access and current data retrieval
- **Source Verification Integration**: Native source verification capability for search result credibility and information validation
- **Native Search Intelligence**: Query validation and suggestion capabilities for search optimization and quality enhancement
