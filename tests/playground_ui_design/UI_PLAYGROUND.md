# UI Playground 

```bash
cd /Users/seanivore/Development/modular-agent-orchestrator

```

The playground lets you:

Experiment with the 4-color palette (Yellow focus, Light blue accent, White normal, Pink emphasis)
Try different character combinations for bullets and icons
Adjust spacing and alignment (the critical gap between anchors and text)
Save/load different design configurations
See real-time preview of how changes affect the interface

------ 


### Visual Brand Identity 

- We don't use emojis 
- If we need a visual, we can use very specific characters 
- Claude Code examples 
  - An * that shrinks and grows as it is thinking 
  - Even the bullet points are custom blocks that fill in when done 
  - ※ <-- is one they use 
  - ⏺ <-- this one they keep by the AI's recent message

- Looks like they only use four colors which makes sense 
  - Yellow is the main focus 
  - Light blue is an accent for secondary information 
  - White is the normal text 
  - Pink and bold for things like a path, the Claude Code name 
  - Slightly darker light blue for icons --> there is a check mark and the !
  - A faded tan for things like numbers from a list 

- They are using the icons, numbers, even the ! from my command, > from a slash command I ran, to anchor things along the left side of the screen
