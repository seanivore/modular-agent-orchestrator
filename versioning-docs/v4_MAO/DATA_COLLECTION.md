# Data Collection 

## Intention 

- Collecting data on personal usage of the application creates intregue 
- Encourages engagement, pushes User to spend more time in the app 
- Give them "bragging rights" within technical or work circles 

**MOST IMPORTANTLY:** Personal data creates the feeling that the technology has emotional intelligence 

### Interesting Collected *Data For A User* 

- **Longevity metrics**
  - Number of hours logged in with app running 
  - Number of workflows created 
  - Grand total of all workflows executed 
  - Nuber of tools used by agents and Orchestrator since first login 
  - Number of times the app has been launched 
  - Number of agents assigned tasks 
  - Totall documents produced over time 
- **Time-based metrics**
  - Average time spent creating a new workflow 
  - Average workflow duration 
- **Tokens and cost metrics**
  - Average cost per workflow 
  - Average tokens per workflow 
  - Highest token count per workflow 
  - Total cost of all workflows executed 
  - Total tokens used by all workflows executed 
  - Most cost efficient workflow amount 
  - Most expensive workflow cost 

### General Data Collection 

- **Longevity metrics**
  - Number of hours with app running 
  - Number of agents that Mao has spawned since birth  
  - Grand total of all workflows created; all workflows executed  
  - Number of tools used by agents and Orchestrator since first login 

- **Over-Time metrics**
  - Monthly counts of workflows created
  - Chart of number of spawned agents over time 

- **Industry Value Metrics** 
  - Most used tools over time 
  - Most used models 
  - Most accurate models 
  - Most cost efficient models 
  - Average tokens per workflow 
  - Difference in token usage between models 

- **User-AI Interaction Behavior Metrics** 
  - Messaging demeanor 
  - Off topic conversation 
  - Conversation length 
  - Conversation style 
  - Conversation tone 
  - Conversation topic 
  - Conversation topic diversity 
  - Conversation topic depth 
  - Conversation topic breadth 
  - Conversation topic complexity 
  - Conversation topic novelty 
  - Conversation frequency 

- **User Agentic Automation Need Metrics** 
  - How often does the user ask for help 
  - How often does the user ask for help with a specific task 
  - Categories of types of tasks the user is asking for help with 
  - Open or closed-ended workflow
  - How much freedom does the User give the AI 
  - How much freedome does User give AI to complete the task by adjusting the workflow
