# Workflow Engine Core - Clean Implementation Specification
*Simple, focused orchestration following proven SFA patterns*

## **Domain Overview**
The Workflow Engine Core transforms user goals into executable workflows and manages the complete execution lifecycle. It builds on MCP Integration Hub and Tool Integration Framework to provide the orchestration brain of MAO.

**Core Functions:**
1. **Conversation → JSON Config → Setup Script** (following SFA pattern)
2. **Agent Handoff Coordination** (context packages via Files API)
3. **Workflow State Management** (Memory MCP tracking)
4. **Session Recovery** (interrupted workflow continuation)

            "variables": self._extract_variables(workflow_spec)

## **Component B: Agent Orchestration**
*Coordinates agent handoffs with context packages*

### **Simple Implementation**

```python
# orchestrator/agent_orchestrator.py
class AgentOrchestrator:
    def __init__(self):
        self.memory_mcp = MemoryMCPManager()
        self.files_api = FilesAPIManager()
        self.tool_manager = ToolManager()
        
    def execute_workflow_phase(self, workflow_id: str, phase: dict):
        """Execute a workflow phase with agent coordination"""
        
        # Get workflow context from Memory MCP
        workflow_context = self.memory_mcp.get_workflow_context(workflow_id)
        
        # Prepare agent handoff package
        handoff_package = self._create_agent_package(
            workflow_id, 
            phase, 
            workflow_context
        )
        
        # Store package via Files API
        package_id = self.files_api.save_agent_package(workflow_id, handoff_package)
        
        # Track phase start in Memory MCP
        self.memory_mcp.update_workflow_state(
            workflow_id,
            f"Phase started: {phase['name']} (Package: {package_id})"
        )
        
        return {
            "package_id": package_id,
            "agent_instructions": handoff_package["instructions"],
            "tool_buttons": handoff_package["tool_buttons"],
            "callback_info": handoff_package["callback"]
        }
    
    def _create_agent_package(self, workflow_id: str, phase: dict, context: dict):
        """Create complete agent handoff package"""
        
        # Generate executable tool buttons for this phase
        tool_buttons = {}
        for tool_name in phase.get("tools", []):
            tool_buttons[tool_name] = self.tool_manager.create_button_snippet(
                tool_name,
                {"workflow_id": workflow_id, "phase": phase["name"]},
                phase.get("model", "claude-sonnet-4")
            )
        
        return {
            "workflow_id": workflow_id,
            "phase_info": phase,
            "previous_deliverables": context.get("deliverables", []),
            "tool_buttons": tool_buttons,
            "instructions": self._generate_agent_instructions(phase, context),
            "callback": {
                "workflow_id": workflow_id,
                "phase_name": phase["name"],
                "callback_endpoint": f"/workflow/{workflow_id}/callback"
            }
        }
    
    def handle_agent_callback(self, workflow_id: str, phase_name: str, results: dict):
        """Process agent completion and continue workflow"""
        
        # Update Memory MCP with results
        self.memory_mcp.update_workflow_state(
            workflow_id,
            f"Phase completed: {phase_name} - {results.get('status', 'success')}"
        )
        
        # Store deliverables in Files API
        if results.get("deliverables"):
            self.files_api.save_deliverables(workflow_id, phase_name, results["deliverables"])
        
        # Determine next phase
        return self._continue_workflow(workflow_id, phase_name, results)

# orchestrator/workflow_state.py
class WorkflowStateManager:
    def __init__(self):
        self.memory_mcp = MemoryMCPManager()
        
    def track_workflow_progress(self, workflow_id: str, update: str):
        """Simple progress tracking"""
        timestamp = datetime.now().isoformat()  # Timestamps for LOGGING, not filenames
        
        # Single source of truth: Memory MCP
        self.memory_mcp.update_workflow_state(
            workflow_id,
            f"{timestamp}: {update}"
        )
    
    def get_workflow_status(self, workflow_id: str):
        """Get current workflow status"""
        return self.memory_mcp.get_workflow_context(workflow_id)
    
    def recover_interrupted_workflow(self, workflow_id: str):
        """Handle session recovery"""
        context = self.memory_mcp.get_workflow_context(workflow_id)
        if not context:
            return None
            
        # Analyze context to determine recovery actions
        return {
            "workflow_id": workflow_id,
            "context": context,
            "recovery_actions": self._plan_recovery(context),
            "can_continue": True
        }

# orchestrator/workspace_manager.py
class WorkspaceManager:
    def __init__(self):
        self.base_workspace = Path.home() / "mao_workflows"
        
    def create_workspace(self, workflow_id: str, custom_command: str):
        """Create workspace with clean naming (NO timestamps in filenames)"""
        
        # Use custom command for directory name (hyphens for filesystem)
        directory_name = custom_command.replace(" ", "-")
        workspace_path = self.base_workspace / directory_name
        
        # Create directory structure
        workspace_path.mkdir(parents=True, exist_ok=True)
        
        # Standard subdirectories
        (workspace_path / "deliverables").mkdir(exist_ok=True)
        (workspace_path / "metadata").mkdir(exist_ok=True)
        
        # Copy config and script for reference
        command_filename = custom_command.replace(" ", "-")
        use_case_dir = f"configs/use_case/{command_filename}"
        
        # Copy config to workspace
        shutil.copy(
            f"{use_case_dir}/config.json",
            workspace_path / f"{command_filename}-config.json"
        )
        
        # Copy executable script for reference
        shutil.copy(
            f"/usr/local/bin/{command_filename}",
            workspace_path / f"{command_filename}.sh"
        )
        
        return str(workspace_path)
    
    def export_workflow_metadata(self, workflow_id: str, workspace_path: str):
        """Export Memory MCP data and execution stats when workflow completes"""
        
        # Get complete workflow context from Memory MCP
        workflow_log = self.memory_mcp.get_workflow_context(workflow_id)
        
        # Export to metadata directory
        metadata_dir = Path(workspace_path) / "metadata"
        
        with open(metadata_dir / "workflow-log.json", 'w') as f:
            json.dump(workflow_log, f, indent=2)
        
        # Create execution stats (cost, timing, etc.)
        stats = {
            "workflow_id": workflow_id,
            "completed": datetime.now().isoformat(),
            "total_cost": self._calculate_total_cost(workflow_log),
            "execution_time": self._calculate_duration(workflow_log),
            "phases_completed": self._count_phases(workflow_log)
        }
        
        with open(metadata_dir / "execution-stats.json", 'w') as f:
            json.dump(stats, f, indent=2)
    
    def organize_deliverables(self, workspace_path: str, final_files: list):
        """Organize ONLY final deliverables (drafts stay in Files API)"""
        deliverables_dir = Path(workspace_path) / "deliverables"
        
        # Move only final outputs to deliverables (paid tokens)
        for file_path in final_files:
            if Path(file_path).exists():
                shutil.move(file_path, deliverables_dir / Path(file_path).name)
```

## **Integration Flow**

### **Conversation → Executable Workflow**
```
1. User: "Create marketing strategy for startup"
2. ConversationBridge.create_workflow_from_conversation()
3. Generate JSON config (same format as human-created)
4. Run setup_workflow.sh (same script humans use)
5. Result: `marketing-strategy-startup` command installed
6. User runs: `marketing-strategy-startup`
```

### **Workflow Execution**
```
1. Load config from use-case directory
2. WorkflowStateManager tracks progress in Memory MCP
3. AgentOrchestrator creates handoff packages via Files API
4. Agent executes with tool buttons, calls back with results
5. Continue until all phases complete
6. WorkspaceManager organizes final deliverables
```

### **Session Recovery**
```
1. User: `mao --continue`
2. WorkflowStateManager.recover_interrupted_workflow()
3. Memory MCP provides complete context
4. Resume from last completed phase
```

1. **Conversation** → use-case config generation
2. **Execution** → Memory MCP state tracking  
3. **Agent handoffs** → Files API context packages

### **Dependencies**
- **MCP Integration Hub**: Memory MCP state management, Files API agent packages
- **Tool Integration Framework**: Human button generation, tool discovery
- **Terminal UI/UX System**: Command execution, progress monitoring
- **CLI System**: Dynamic command registration and routing

- **Entry Point**: Custom commands route through `mao_v4.py` dynamic CLI system

- **Agent Coordination**: Files API handles all draft storage and handoff packages
- **Tool Execution**: Human buttons work with any AI model via Code Execution
- **Session Recovery**: Memory MCP provides complete workflow context restoration
