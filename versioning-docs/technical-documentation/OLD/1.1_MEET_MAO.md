## Why M-A-O? 

/maʊ̯/ --> pronounce it like "mau" (no "H" sound). Think of a cat. Mao Mao meow. 

### **Modular** 

In making Mao, the goal was to create a single system that can be used for any use-case. The agent is 'empty', with no specifics pointing towards a use-case in the code. When given a use-case, it is broken into variables and input into the system using a setup script. If you have a new tool or LLM model to add, you just drop in the necessary files. 'Plug-and-play', as they say. 

### **Agentic** 

Agents are systems where the AI has been given agency; they do more than run on a predetermined loop. In Mao's case the system creates the start of a workflow, then has complete autonomy to direct the workflow, building or changing it as tasks are completed and the AI has new information to decide how to proceed. Unless specifically instructed, Mao maintains control over how to accomplish the task, and larger project. 

### **Orchestrator** 

Orchestration is what makes this system able to handle more complex workflows, while making the over human experience as simple as possible. When you set up a workflow, you work with the AI orchestrator. If you want, they will plan everything, delegate tasks as needed, report on progress, and adjust the flow as needed to achieve provided goals.
