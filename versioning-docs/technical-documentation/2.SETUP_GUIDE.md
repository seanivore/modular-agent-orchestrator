## 🆘 Quick Troubleshooting

### **MAO seems slow or unresponsive**
- Check your internet connection (MAO needs to communicate with AI providers)
- Verify API keys are valid and have sufficient credits
- Try `--budget-mode` to use free models if you're hitting rate limits

### **"No suitable model found" error**
- Ensure at least one valid API key is configured
- Check that your API keys have the necessary permissions
- Gemini is free and provides a good fallback option

### **Workflows seem incomplete**
- Use `--verbose` to see MAO's decision-making process
- Check if you hit API rate limits during execution
- MAO can resume interrupted workflows with `--continue`

### **Unexpected behavior**
- MAO learns from interaction patterns - try being more specific about your goals
- Check the `--help` for advanced options
- Remember: MAO is autonomous but responds well to clear communication
