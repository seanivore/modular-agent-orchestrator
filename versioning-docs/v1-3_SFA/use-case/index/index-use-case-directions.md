
# Index Building 

## Directions 

1. Open DOCUMENT_LIST.md 
2. Choose one document at random from those that have not been crossed off yet. 
3. Open that document from the path indicated on the list. 
4. Edit the DOCUMENT_LIST.md file by crossing off the document you are about to review. 
5. Save the updated DOCUMENT_LIST.md file, leaving it where it is. 
6. Review the document you chose from the list. 
7. Determine what categories of information one might use to find the document again. 
8. Record categories at the CATEGORY_LISTS.md document, creating a new list for the category if it doesn't exist. 
9. Add the document's name to all of those lists. A document should be on as many lists as it fits into. 
10. When finished with a document, exit the file without making any changes.

Repeat until all files on DOCUMENT_LIST.md have been reviewed. 

## Tips 

There are a few categories we can add to the CATEGORY_LISTS.md file off the bat. 

   - Grouped by Strategy Name 
   - Grouped by Similar Tactic Involved 
   - Grouped by Customer Type Influenced 
   - Grouped by Outcome of Strategy 
   - Grouped by Vocal Characteristic Involved 

Keep in mind that these categories are to find *that same* document again. They are all research and strategy documents. This means we won't need to get into any specifics of a category that are used in script examples. Theses would be categories like what urgency was used, what kind of objection was handled, etc. 

All documents reviewed will be in the same 'voice-mkt-sfa' directory.
