# Promotions & Marketing Materials

This folder contains all marketing, sales, and promotional materials for Mao - separate from technical documentation.

## Folder Structure

### `/visuals/`
- **`interactive_demos/`** - HTML/CSS/JS interactive demonstrations
- **`diagrams/`** - Mermaid diagrams, flowcharts, architecture visuals  
- **`infographics/`** - Static graphics for presentations and web

### `/case_studies/`
- Real-world examples of Mao's capabilities
- Before/after productivity demonstrations
- Customer success stories

### `/presentations/`
- Pitch decks for investors/partners
- Conference presentations
- Demo scripts

### `/marketing_assets/`
- Website content
- Social media graphics
- Brochures and one-pagers

## Visual Strategy

**Target Audience:** Non-technical decision makers who need to understand:
1. Revolutionary productivity gains through parallel AI agents
2. Cost advantages over traditional AI solutions  
3. Global scalability with multilingual support
4. Practical implementation and real results

**Key Messages:**
- "From Assistant to Employee" - AI that manages projects, not just tasks
- "5 Parallel Agents = Exponential Output" - Same goal, multiple brilliant solutions
- "Real Results" - Verified productivity gains and cost savings

## Usage

These materials are designed for:
- Business development meetings
- Investor pitches  
- Conference presentations
- Website integration (Jekyll/GitHub Pages compatible)
- Social media campaigns
