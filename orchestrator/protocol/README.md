# Protocol Directory
*Experimental strategy documents for testing new Mao behaviors and features*

## Purpose
This directory contains experimental protocols that we iterate on, test, and refine. Each protocol focuses on a specific behavior or feature we're developing.

## Structure
- **`protocol_NAME.md`** - Strategy and experimental design
- **`protocol_NAME_implementation.md`** - Code locations and success metrics

## Current Protocols

### Emotional Intelligence
- **Strategy**: `emotional_intelligence.md` - Core philosophy, context recognition patterns, strategic challenges
- **Implementation**: `emotional_intelligence_implementation.md` - Code locations, success metrics, tuning variables

## Adding New Protocols
When experimenting with new behaviors:

1. Create `protocol_EXPERIMENT_NAME.md` for strategy/design
2. Create `protocol_EXPERIMENT_NAME_implementation.md` for tracking
3. Document what you're testing and how you'll measure success
4. Iterate based on real user feedback
