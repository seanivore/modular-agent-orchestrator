# App UI Core Concepts

this is about cognitive flow, not visual categorization! 🧠✨
The colors aren't saying "this is a button" or "this is a warning" - they're saying:

Pink = "STOP and focus here" (cognitive interrupt)
Yellow = "Flow with this" (natural conversation)
Light Blue = "This is trustworthy action" (safe to click)
Gray = "This is your space" (familiar/background)

It's neurocognitive design - working WITH how attention and processing actually function!
