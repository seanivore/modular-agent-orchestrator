Configuration

Customizing your Mao orchestrator

$ find ~/.config/mao -name "*.json" | head -5

Configuration Architecture

Mao uses modular JSON configuration files for maximum flexibility. Each component is standalone and atomic:

json agents/default.json Default agent configuration
json tools/filesystem.json File operation tool definition
json workflows/research.json Research workflow pattern
json ui/colors.json Terminal color scheme
$ cat agents/example.json

Agent Configuration

Configure specialized agents for different tasks:

{ "name": "research_agent", "description": "Specialized for research and analysis tasks", "model": "claude-sonnet-4", "temperature": 0.3, "system_prompt": "You are a research specialist...", "tools": ["web_search", "document_analysis", "citation_manager"], "memory_enabled": true, "cost_limit": 0.50 }
$ cat tools/custom_tool.json

Tool Development

Create custom tools with JSON definitions:

{ "name": "file_analyzer", "version": "1.0.0", "description": "Analyzes file structure and content", "file_path": "tools/file_analyzer.py", "button_path": "tools/button_file_analyzer.py", "ui_path": "tools/ui_file_analyzer.py", "operations": { "analyze": { "description": "Analyze file content and structure", "required_params": ["file_path"], "optional_params": ["depth", "format"] } }, "models_supported": ["all"], "cost_estimate": 0.001 }
$ mao config --list

Runtime Configuration

Modify Mao's behavior through configuration commands:

cmd mao config set model claude-sonnet-4 Set default AI model
cmd mao config set memory.persist true Enable persistent memory
cmd mao config set ui.theme classic Set terminal color theme
cmd mao config set cost.daily_limit 5.00 Set daily cost limits
