$ cat installation.md

Installation

Mao is designed as a local-first terminal application. Install it with a single command:

curl -sSL https://get.mao.dev | bash

This installer will:

  • Download the latest Mao release
  • Set up the modular tool ecosystem
  • Configure your terminal interface
  • Initialize the memory system
$ mao init --help

First-Time Setup

After installation, initialize your Mao workspace:

mao init

This creates your configuration directory structure:

dir ~/.config/mao/ Main configuration directory
dir tools/ Modular tool definitions
dir agents/ Agent configuration files
dir workflows/ Saved workflow patterns
$ mao chat --interactive

Your First Conversation

Launch the interactive chat interface to start orchestrating AI agents:

mao chat

The terminal interface provides:

  • Conversation Flow: Natural language interaction with AI agents
  • Agent Routing: Automatic selection of appropriate specialized agents
  • Tool Integration: Seamless access to your modular tool ecosystem
  • Memory Persistence: Context maintained across sessions
