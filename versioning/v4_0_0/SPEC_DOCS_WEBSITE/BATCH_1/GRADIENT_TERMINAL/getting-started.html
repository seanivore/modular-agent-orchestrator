Installation

Install Mao with a single command and start orchestrating AI agents immediately:

$ Installation
curl -sSL https://get.mao.dev | bash
[INFO] Downloading Mao installer...
[INFO] Setting up modular tool ecosystem...
[INFO] Configuring terminal interface...
[SUCCESS] Mao installed successfully

Initial Setup

Initialize your Mao workspace with the configuration system:

1

Initialize Workspace

mao init

Creates configuration directories and default settings

2

Configure Agents

mao agents setup

Set up AI model preferences and API keys

3

Start Chatting

mao chat

Launch the interactive terminal interface

Your First Workflow

Experience multi-agent orchestration with a simple research task:

Key Concepts

Local First

Runs entirely on your machine with no cloud dependencies for core functionality

Modular Tools

JSON-based tool system with automatic discovery and template-driven creation

Agent Orchestration

Intelligent routing between specialized AI agents based on task requirements

Memory System

Persistent context and state management across sessions and workflows
