Modular Configuration System

Mao's atomic JSON configuration system provides maximum flexibility while maintaining simplicity and discoverability.

Agent Configurations

Define specialized AI agents for different task domains with custom prompts, models, and tool access.

agents/research_specialist.json
{
  "name": "research_specialist",
  "description": "Deep research and analysis",
  "model": "claude-sonnet-4",
  "temperature": 0.2,
  "system_prompt": "Expert researcher...",
  "tools": ["web_search", "document_analysis"],
  "memory_enabled": true
}

Tool Definitions

Create custom tools with the 4-file modular pattern for maximum reusability and maintainability.

tools/data_analyzer.json
{
  "name": "data_analyzer",
  "version": "1.0.0",
  "file_path": "tools/data_analyzer.py",
  "button_path": "tools/button_data_analyzer.py",
  "ui_path": "tools/ui_data_analyzer.py",
  "operations": {
    "analyze": {
      "description": "Analyze dataset patterns",
      "required_params": ["data_path"]
    }
  }
}

Workflow Patterns

Define reusable workflow templates that orchestrate multiple agents and tools in sophisticated patterns.

workflows/parallel_research.json
{
  "name": "parallel_research",
  "description": "Multi-agent parallel research",
  "steps": [
    {
      "name": "topic_analysis",
      "agent": "research_specialist"
    },
    {
      "name": "parallel_search",
      "type": "parallel",
      "agents": ["web_researcher", "academic_researcher"]
    }
  ]
}

UI Customization

Customize the terminal interface colors, themes, and behavior to match your preferences and workflow needs.

ui/theme.json
{
  "name": "custom_theme",
  "colors": {
    "primary": "#00ff00",
    "secondary": "#00cc00", 
    "accent": "#ffff00",
    "background": "#000000"
  },
  "animations": {
    "typing_speed": 50,
    "fade_duration": 300
  }
}

Configuration Commands

Manage your Mao configuration through the command-line interface:

mao config list
Show all configuration values
mao config set model claude-sonnet-4
Set default AI model
mao config set memory.persist true
Enable persistent memory
mao config validate
Validate all configuration files

Automatic Discovery

Mao automatically discovers and loads configurations through directory scanning - no hardcoded lists or manual registration required.

config-discovery
mao $ config discover
[INFO] Scanning ~/.config/mao/...
[INFO] Found 12 agent configurations
[INFO] Found 8 tool definitions
[INFO] Found 5 workflow patterns
[SUCCESS] Configuration discovery complete
