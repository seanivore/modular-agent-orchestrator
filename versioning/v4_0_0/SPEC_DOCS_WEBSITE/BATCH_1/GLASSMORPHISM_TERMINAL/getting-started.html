Installation & Setup

Install Mao with a single command and start orchestrating AI agents immediately.

installation
$ curl -sSL https://get.mao.dev | bash
[INFO] Downloading Mao installer...
[INFO] Setting up tool ecosystem...
[SUCCESS] Mao installed successfully

Quick Initialize

Set up your Mao workspace with automatic directory structure creation and default configurations.

mao init

First Conversation

Launch the interactive terminal interface and start your first AI agent conversation.

mao chat

Explore Tools

Discover available tools and workflows with the built-in exploration commands.

mao tools list

Configure Agents

Customize agent behavior and create specialized configurations for different tasks.

mao agents configure
