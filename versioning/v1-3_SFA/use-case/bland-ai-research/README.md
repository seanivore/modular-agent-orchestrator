# Bland AI Research Workflow

## Overview
This Single-File Agent workflow conducts comprehensive research on Bland AI's voice platform capabilities and creates optimized documentation for voice script formatting. The workflow is designed to support teams implementing AI voice technology for telemarketing applications, with a focus on script optimization and modulation techniques.

## Workflow Phases

### Phase 1: Research & Analysis
- Conducts detailed research on Bland AI's platform and voice script optimization
- Investigates script formatting requirements and best practices
- Compiles findings on voice modulation techniques, including tone, pace, emphasis, and pauses
- Generates a comprehensive research report saved as `BLAND_AI_RESEARCH.md`

### Phase 2: Cheat Sheet Creation
- Distills research findings into a concise, one-page reference guide
- Creates a practical "Voice Script Modulation Cheat Sheet"
- Focuses on actionable formatting techniques and examples
- Produces a scannable reference document saved as `SCRIPT_MODULATION_CHEAT_SHEET.md`

## Usage

To run the workflow, use the following command:

```bash
sfa bland-ai-research
```

## Expected Outputs

The workflow generates two key documents in the `/findings/` directory:

1. `BLAND_AI_RESEARCH.md`
   - Comprehensive research report on Bland AI
   - Analysis of voice platform capabilities
   - Detailed script formatting guidelines
   - Industry best practices and techniques

2. `SCRIPT_MODULATION_CHEAT_SHEET.md`
   - Single-page quick reference guide
   - Formatting examples for voice modulation
   - Before/after script samples
   - Visual organization of key techniques
   - Platform-specific requirements

## Notes
- Ensure you have proper access to web search tools for research phase
- Output files will be created in the specified paths under the `voice-mkt-sfa/findings/` directory
